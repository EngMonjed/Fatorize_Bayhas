# تسليم من محادثة الهيكلية العامة: "الكروب" صار حقيقة مخزَّنة، مش مُستنتَجة

## الخلفية (باختصار)

اكتُشف بق حقيقي: مودال اختيار المنتجات بفاتورة بيع/شراء (وأي مكان مشابه)
كان بيعيد بناء "الكروب" (مجموعة مقاسات بنفس السعر) من تطابق
(`selling_price` + `age_type`) — طريقة هشة، فشلت فعلياً مع منتج حقيقي
عنده نفس اللون متكرر بأكتر من كروب سعري.

**الحل الجذري:** عمود جديد `product_sizes.group_key` — بيتخزّن **مرة
وحدة** وقت إنشاء/تعديل المنتج (`product_add.php` عبر `product_save_helper.php`
المُحدَّث)، وصار **مصدر الحقيقة الوحيد** لأي تجميع كروب بأي مكان بالنظام.

## شو اتغيّر فعلاً (منفَّذ ومُسلَّم)

| الملف | التغيير |
|---|---|
| `product_sizes_ret` (قاعدة بيانات) | عمود جديد `group_key VARCHAR(50)` |
| `includes/product_save_helper.php` | `saveProductSizes()` بتخزّن `group_key`؛ `syncProductVariants()` بتقرأه مباشرة (مو تعيد استنتاجه) |
| `inventory/import_products.php` | عمود CSV اختياري جديد `group_no` — بيتحوّل لـ`group_key` صريح |

## المطلوب منكم بالضبط (بمحادثتكم، على ملفاتكم)

أي ملف عنده منطق "تجميع كروب" (بحث منتج، مودال اختيار، عرض جدول)، لازم:

1. **يضيف `s.group_key` لأي `SELECT` من `product_sizes`** (بجانب `selling_price`, `packet_qty`... الموجودين أصلاً)
2. **يستبدل مفتاح التجميع الحالي** — أينما شفت شي شبيه:
   ```js
   const key = `${it.product_id}_${it.selling_price}_${it.age_type}_${it.color_id}`;
   ```
   يصير:
   ```js
   const key = `${it.product_id}_${it.group_key}_${it.color_id}`;
   ```
3. **نفس الشي لأي مفتاح تلوين/ترقيم بصري للكروبات** ("كروب ١"، "كروب ٢") — يعتمد على `group_key` بدل `selling_price`

## ⚠️ الملفات المرشَّحة للفحص (حسب التوثيق الموجود)

- `sales/sales_index.php`, `sales/invoice_new.php`, `sales/invoice_edit.php`
- `purchases/index.php`, `purchases/invoice_new.php`, `purchases/invoice_edit.php`
- أي صفحة مرتجعات (`sales/returns.php`, `purchases/returns.php`) — لو فيها نفس نمط عرض/تجميع

## ملاحظة توافق مهمة

بيانات موجودة أصلاً (منتجات قبل هالتحديث) اتعبّت رجعياً بـ`group_key`
مُشتق من (`selling_price`+`packet_qty`) — نفس السلوك القديم بالضبط، بس
مخزَّن هلق. يعني **ولا منتج قديم رح ينكسر**، بس لسا معرَّض لنفس بق
"نفس السعر بكروبين مختلفين" لو صادف موجود بمنتج قديم قبل التحديث —
لازم فحص يدوي لو في شك بمنتج معيّن.
